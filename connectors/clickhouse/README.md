# ClickHouse

Connect agents to ClickHouse so they can explore events and metrics with fast
analytical SQL.

## Analyze your data

- Count, group, and chart large tables in seconds.
- Read arrays, maps, and tuples as structured data.
- Inspect databases, tables, and columns to find what a question needs.

## Make changes when you allow it

With **Read and write** access, agents can also insert data and create or alter
tables. With **Read-only** access, every query runs with ClickHouse's read-only
setting, so data, schema and settings cannot change. Your user's grants and settings profile always
apply.
