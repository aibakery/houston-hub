# Granola

Connect Granola so your agents can find recent meetings, read their AI summaries,
attendees and calendar details, and go through full transcripts. They can browse
by date, folder or space, for example to prepare a weekly recap, pull action items
into another tool, or answer questions about what was said in a call.

Access is read-only: agents cannot create, edit or delete notes. They see exactly
the notes your Granola API key can read. A personal key covers your own and
shared notes, and a workspace key covers team notes. Granola API keys require a
Business or Enterprise plan.
