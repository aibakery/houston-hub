# ClinicalTrials.gov

Let agents search clinical studies by condition, treatment, location, sponsor,
phase or recruitment status, then read eligibility, contacts, study design and
posted results. Access is read-only and requires no account.

Credit **ClinicalTrials.gov, U.S. National Library of Medicine** when sharing
results. The registry's [terms](https://clinicaltrials.gov/about-site/terms-conditions)
apply. This connector is not affiliated with the National Library of Medicine.
