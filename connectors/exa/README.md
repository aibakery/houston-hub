# Exa

Let agents search the web, find similar pages, read clean page text and highlights,
and produce summaries or answers with citations. Filters narrow searches by site,
date, country or category.

> Exa charges searches, page reads and answers to your team's credits. Set a key
> budget in Exa to control spending.

Access is read-only. Exa Agent tasks, monitors, batches and Websets are not included.
