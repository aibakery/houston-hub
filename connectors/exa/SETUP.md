# Connect Exa

1. In the [Exa dashboard](https://dashboard.exa.ai/), select the team whose credits
   Houston should use.
2. Open [API Keys](https://dashboard.exa.ai/api-keys), create a key and copy it.
3. Paste it into Houston's **API key** and save the connection.

> Searches, page reads and answers spend your team's Exa credits. Set a budget and
> rate limit for this key on the API Keys page.

## Advanced

If requests exhaust credits or a budget, check [Billing](https://dashboard.exa.ai/billing)
and the key's limits. Features depend on your plan; pages requiring sign-in or
blocking crawlers may be unavailable. Replace deleted keys in Houston.

[Billing and limits](https://exa.ai/docs/admin/billing).
