# FamilySearch

Explore and maintain your family history through your FamilySearch account.

- Read people, relationships, pedigrees, sources, discussions, memories, change history, and matches.
- Work with user trees, groups, places, standardized dates, names, and controlled vocabularies.
- With **Write**, contribute and update records, manage sources and memories, merge people, and restore changes.

**Read** is the default and permits only reads. **Write** adds mutations. Houston enforces this choice independently of your FamilySearch account permissions. Connections are personal because each user must use their own FamilySearch authorization.

OAuth sign-in and existing access tokens are supported for Production and Beta. Tokens expire after 24 hours or 60 minutes of inactivity; reconnect when needed. Production access and individual API capabilities depend on FamilySearch approval.

> FamilySearch requires express written permission before its content can be used with AI, and advance disclosure for AI-created or modified contributions. See its [AI addendum](https://developers.familysearch.org/main/docs/ai-disclosure-addendum).

The connector covers the public API reference. Historical-record search and restricted ordinance APIs are not publicly available through this integration. Record hints can link you to FamilySearch to view records.
