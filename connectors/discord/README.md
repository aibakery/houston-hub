# Discord

Let agents keep up with a Discord community: summarize what happened in a busy
channel, find the thread where something was decided, search the whole server
for a topic, or look up who a member is and which roles they have.

With read and write access, agents can also take part: post an announcement,
reply to a question, start a thread, react with an emoji, or edit and delete
what they posted. Everything they post appears as Houston's bot, never as you,
and does not ping anyone unless the agent deliberately mentions specific people
or roles.

Houston adds its bot to one server you choose. Each connection covers that one
server, and Houston cannot see servers it was not added to, or the channels its
role is not allowed to view. Read-only access lets agents read and search, but
never post.

Continue with Discord, pick your server and confirm the bot's permissions. See
[Connect a Discord server](SETUP.md).
