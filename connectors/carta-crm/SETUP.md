# Connect Carta CRM

1. Ask an organization admin to generate an API key in Carta CRM's **Settings**.
2. Paste it into Houston's **API key**.
3. Choose **Read-only**, or **Read and write** for record changes, then save.

> The key uses its owner's permissions and enabled modules. Creating contacts or
> records with websites can start data enrichment.

## Advanced

Request a sandbox from Carta for testing. Manage users, teams, custom fields,
pipeline stages, attachments, campaigns and subscription closings in Carta CRM.
If data is unavailable, check the key owner's access and enabled modules.

[CRM API guide](https://docs.carta.com/crm/guides/overview/introduction/).
