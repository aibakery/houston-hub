# Linear

Connect Linear so your agents can review your workspace: find and search issues
by team, status, assignee, label, priority or date, read their descriptions,
sub-issues and comments, and follow teams, projects, cycles, statuses and labels.

With read and write access, agents can also file issues, change their status,
assignee, labels, priority and other details, and comment or reply on issues.
Linear notifies the people subscribed to those issues.

Linear's own permissions still apply: agents see only the teams your account or
API key can access. Your credentials stay on Houston's server.
