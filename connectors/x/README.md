# X

Search public posts, browse profiles and timelines, and follow mentions and
conversations on X. Search the last seven days or explore older posts when your
X developer account has full-archive access.

This connector reads public information. It cannot access private account data,
home feeds, bookmarks, or direct messages, and it cannot publish posts.

Connecting requires an X developer account and an app bearer token. X charges
usage to your developer account; available searches depend on your API access
and credits. Your token stays on Houston's server.
