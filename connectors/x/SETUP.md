# Connect X

1. Open the [X Developer Console](https://console.x.com/) and create or select an app.
2. Under **Keys and tokens**, generate or copy the app's **Bearer Token**. This is
   not the API key, API key secret, or a user's access token.
3. Paste it into **App bearer token** below. Ensure your X developer account has
   the endpoint access and credits needed for your requests.

X bills usage to your developer account. Your token stays on Houston's server.
