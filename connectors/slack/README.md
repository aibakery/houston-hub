# Slack

Let agents catch you up on Slack: summarize a busy channel, find the thread where
a decision was made, list the messages that mention you, or pull an attachment
someone shared. They see the channels, private channels and direct messages you
can see, and search the same way you do in Slack.

With read and write access, agents can also act as you: post or reply in a
thread, send a direct message, edit or delete your messages, react with an
emoji, or share a file. Everything they post appears under your name.

Read-only access lets agents read and search, but never post. Each connection
covers one Slack workspace; add another connection for each additional
workspace.

Connect with Slack in one click: pick your workspace and allow access. Your
authorization stays on Houston's server. See [Connect your Slack account](SETUP.md).
