# WooCommerce

Connect your WooCommerce store so your agents can look up orders and customers,
follow sales and top sellers, check stock and prices, and read reviews, coupons,
shipping zones and taxes.

With read and write access, agents can also update order statuses, add order notes,
issue refunds, create and edit products, variations and categories, manage customers
and coupons, and adjust shipping, tax and store settings. Refunds can return money
through your payment gateway, and order updates can email your customers. Store
settings, payment methods and webhooks are available only with read and write access,
because they can include payment credentials and webhook secrets.

The connection uses a WooCommerce REST API key from your own store. The key's
permissions and its WordPress user's role still apply. Your keys stay on Houston's
server.
