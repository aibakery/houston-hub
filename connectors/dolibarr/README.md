# Dolibarr

Let agents read customers, products, stock, orders, invoices, payments and bank
accounts. **Read and write** also permits record changes, stock movements,
order/invoice validation and recording payments.

> Read-only access requires a non-admin Dolibarr user with read-only permissions.
> The user's permissions remain the final limit on the API key.

Supports Dolibarr 16+ over HTTPS, at the domain root or within up to two folders.
