# bioRxiv and medRxiv

Let agents search preprints, read abstracts and every version, find journal
publications, and download available PDFs. No account is required; access is read-only.

> Preprints have not completed peer review. Automated PDF downloads may be blocked;
> open the PDF link in your browser when needed.

Search uses [Europe PMC](https://europepmc.org) and may lag a day; other data comes
from the [provider API](https://api.biorxiv.org). Respect each preprint's licence
and [Europe PMC's attribution terms](https://europepmc.org/Copyright).
This connector is not affiliated with the providers.
