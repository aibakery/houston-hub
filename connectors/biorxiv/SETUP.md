# Add bioRxiv and medRxiv

Select **Add connector** in Houston. No account, API key or settings are required.

> Automated PDF downloads may be blocked, especially by medRxiv. Open the PDF
> link in your browser if a download fails.

## Advanced

Search uses Europe PMC and may lag a day; date-range listings use the servers
directly. Check which server holds a DOI when a preprint is missing.

[Provider API](https://api.biorxiv.org) · [Search syntax](https://europepmc.org/searchsyntax).
