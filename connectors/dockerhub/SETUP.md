# Add Docker Hub

Select **Add connection** in Houston. No account, token or settings are required.

> This connector reads public data only. Private repositories, organizations and
> teams are unavailable.

## Advanced

Official images use the `library` namespace. Anonymous lists stop after 100
repositories or 1,000 tags; narrow by name when needed.

[Docker Hub API guide](https://docs.docker.com/reference/api/hub/latest/).
