# Blockscout

Let agents explore public blockchain data:

- Address balances, token holdings, NFTs and activity.
- Transactions, blocks, decoded calls and event logs.
- Tokens, holders, chain statistics and verified contract source code.

Each connection reads one chain and cannot sign or send transactions. Public
explorers require no account; an optional API key provides a separate quota and
avoids some automated-access restrictions. This connector is not affiliated with
Blockscout.
