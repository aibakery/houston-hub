# Attio

Connect Attio so your agents can look up people, companies, deals and any custom
object in your CRM. They can search and filter records, read lists and pipelines,
and catch up on a customer's notes, tasks, comment threads, meetings, call
recordings, email history and files, for example to prepare for a call, summarize
an account or find stalled deals.

Access is read-only: agents cannot create, edit or delete anything in Attio. They
see exactly what your Attio API key's scopes allow, and email message bodies are
never available. API keys are available on every Attio plan.
