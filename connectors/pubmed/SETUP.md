# Add PubMed

1. Add PubMed in Houston. No account is required.
2. Optionally enter **NCBI API key** for a higher request quota, then select
   **Add connection**.

## Advanced

Create a free key under [NCBI account settings](https://account.ncbi.nlm.nih.gov/settings/)
→ **API Key Management**. Paste it into Houston's **NCBI API key**. Creating a
replacement invalidates the previous key; update every connection using it.

Full text is available only for eligible PMC articles. Broad searches are limited
to 9,999 matches; narrow by date or topic.

[PubMed help](https://pubmed.ncbi.nlm.nih.gov/help/).
