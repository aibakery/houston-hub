# WordPress

Connect your self-hosted WordPress site so your agents can read your posts, pages,
drafts and revisions, search the site, and look up media, categories, tags,
comments and authors.

With read and write access, agents can also write and edit posts and pages, save
them as drafts, submit them for review, schedule or publish them, upload images
and other media, manage categories and tags, and approve, reply to, mark as spam
or trash comments. Published posts are public right away, and WordPress may email
subscribers or commenters when content or comments change.

The connection uses an application password from your own WordPress user, so that
user's role still applies: an Author can publish only their own posts, while an
Editor can manage all content and comments. Houston never manages plugins, themes,
users or application passwords.
